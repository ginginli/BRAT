🔧 Fix Index.html Canonical Issue

Resolve "Alternate page with proper canonical tag" for index.html

❌ The Problem

Google Search Console Error:

https://www.bratgenerator.com.cn/index.html

"Alternate page with proper canonical tag"

Why this happens:

  • Google discovered the URL /index.html
  • This page has a canonical tag pointing to /
  • Google sees this as a duplicate page with proper canonical
  • The page should redirect instead of serving content

✅ Current Solution in Place

Your vercel.json already has the correct redirect rule:

{ "redirects": [ { "source": "/index.html", "destination": "/", "permanent": true } ] }

This should redirect /index.html → / with a 301 status.

🚀 Immediate Actions Required

1. Test the Redirect

2. Google Search Console Actions

  1. URL Inspection Tool:
    • Go to Google Search Console
    • Test URL: https://www.bratgenerator.com.cn/index.html
    • Verify it shows "Page is not indexed" or redirects properly
    • Test URL: https://www.bratgenerator.com.cn/
    • Click "Request Indexing" for the root URL
  2. Remove index.html from Google:
    • Go to "Removals" in GSC
    • Request temporary removal of /index.html
    • This speeds up the process
  3. Check Coverage Report:
    • Monitor "Excluded" pages
    • Look for "Alternate page with proper canonical tag"
    • This should decrease over time

3. Additional Verification

⚠️ If the Problem Persists

Possible Causes:

  • Cached redirects: Google might have cached the old response
  • Internal links: Your site might link to /index.html
  • External links: Other sites might link to /index.html
  • Sitemap: The sitemap might include /index.html

Additional Solutions:

<meta name="robots" content="noindex, follow"> <script> if (window.location.pathname === '/index.html') { window.location.replace('/'); } </script>
